Onebrief Network Diagram demo - GitHub Pages

Publish this folder as a website:
1. Open or create the GitHub repository you want to use.
2. Upload index.html and .nojekyll to the repository root, and commit the files.
   README.txt is optional. No Python notebook, server, or extra assets are required.
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select main (or the branch holding index.html), select / (root), and Save.
6. When deployment finishes, copy the URL shown beside Visit site.

GitHub Pages setup guide:
https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

The demo includes fictional example people and relationships.
Each visitor can explore and edit an independent copy in their browser.
Edits are stored locally in that browser; this is not a live shared editing service.
Use File > Save project to download a JSON copy of your edits.

The index.html file is a byte-for-byte copy of the final Onebrief-network-diagram-demo.html.
